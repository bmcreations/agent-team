# agent-team

Role-based delegation across rival agent CLIs, packaged as a Claude Code plugin.

Skills name a role. A per-project config maps the role to an agent, so the same
skill runs on Codex in one repo, Grok in another, and Claude on a machine with
neither installed.

Nothing is implemented yet. The design, its rejected alternatives, and the open
questions are in
[docs/superpowers/specs/2026-09-14-agent-team-design.md](docs/superpowers/specs/2026-09-14-agent-team-design.md).
